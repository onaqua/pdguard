# Конфигурация pdguard

Конфигурация — файл `configs/config.json` в формате JSON. Сервис использует
только стандартную библиотеку, поэтому формат — обычный JSON без YAML/TOML.
Длительности хранятся как числа с единицей в имени поля (`read_timeout_ms`) и
преобразуются в `time.Duration` при загрузке.

Если файл отсутствует, сервис стартует со встроенными рабочими значениями по
умолчанию (`config.Default()`). Путь к файлу задаётся флагом `-config`, переменной
окружения `PDGUARD_CONFIG` или по умолчанию `configs/config.json`.

## Структура файла

```json
{
  "server": { ... },
  "store": { ... },
  "log": { ... },
  "masking": { ... },
  "llm": { ... },
  "default_system": "default",
  "require_system": false,
  "systems": [ ... ]
}
```

### server

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `addr` | string | `:8080` | Адрес прослушивания. |
| `read_timeout_ms` | int | `5000` | Таймаут чтения запроса. |
| `write_timeout_ms` | int | `15000` | Таймаут записи ответа. |
| `idle_timeout_ms` | int | `60000` | Таймаут простоя keep-alive соединения. |
| `max_body_bytes` | int | `16777216` | Максимальный размер тела запроса (16 МиБ). |
| `process_timeout_ms` | int | `5000` | Таймаут обработки одного `/process`. |
| `max_concurrent` | int | `256` | Лимит одновременных обработчиков `/process`; `0` отключает лимитер. |
| `shed_on_429` | bool | `false` | Возвращать 429 вместо очереди при насыщении лимитера. |
| `fail_open` | bool | `true` | При сбое отвечать 200 с неизменённым payload. Отсутствие поля = `true`. |
| `admin_token` | string | `""` | Токен для `/admin/*`; пустой оставляет админ-роуты открытыми. |

`ReadHeaderTimeout` выводится из `read_timeout_ms` (не более 5 с) и защищает от
Slowloris. `max_concurrent` фиксируется при старте: изменение через
`PUT /admin/config` не применяется до рестарта.

### store

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `shards` | int | `256` | Число lock stripes. |
| `ttl_seconds` | int | `600` | Время жизни соответствия `payload_id`. |
| `max_entries` | int | `1000000` | Мягкий лимит числа записей. |
| `max_value_bytes` | int | `8388608` | Максимальный размер запоминаемого payload (8 МиБ). |
| `max_bytes` | int | `1073741824` | Мягкий лимит суммарного размера живых записей (1 ГиБ). |

`max_value_bytes` обязан быть не меньше максимального принимаемого тела: иначе
прямой шаг успешен, соответствие отброшено, и обратный шаг ответит маской.

### log

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `level` | string | `info` | `debug` \| `info` \| `warn` \| `error`. |
| `format` | string | `json` | `json` \| `text`. |
| `sample_every` | int | `0` | Логировать только каждый N-й запрос; `0` и `1` = все. |
| `requests` | bool | `true` | Писать per-request сводку `request` (типы ПД и счётчики) на уровне `info`. Выключите для прогонов на максимальный RPS. |

### masking

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `span_include_labels` | bool | `false` | Расширять каждый span влево на служебное слово («серия 4509» вместо «4509»). |

### llm

Блок настраивает OpenAI-совместимый апстрим для цепочки «чат через LLM»
(`POST /v1/chat/completions`).

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `base_url` | string | `""` | Корень OpenAI-совместимого API. Пусто = встроенная демо-модель без сети. |
| `model` | string | `deepseek-ai/DeepSeek-V4-Flash-0731` | Идентификатор модели в теле запроса. |
| `timeout_ms` | int | `60000` | Таймаут одного вызова апстрима. |
| `stream` | bool | `true` | Запрашивать потоковую форму SSE (AlfaGen отвечает только потоком). |
| `ca_file` | string | `""` | Путь к PEM-файлу с дополнительными корневыми сертификатами; добавляется к системным. |
| `strategy` | string | `token` | Стратегия маски для всех типов ПД в LLM-цепочке. |
| `requests_per_minute` | int | `60` | Общий (на весь процесс) предел вызовов LLM в минуту. `0` — без ограничения; отрицательное значение — ошибка валидации. При исчерпании — `429` с заголовком `Retry-After`. |

Ключ API задаётся **только** переменной окружения `PDGUARD_LLM_API_KEY` — в файле
конфигурации его нет, `/admin/config` его не показывает, в логи он не попадает.

### default_system и require_system

- `default_system` — id системы, обслуживающей запросы без заголовка
  `X-System-Id` (или с неизвестным id).
- `require_system` — `true` включает allow-list: заголовок `X-System-Id`
  становится обязательным, а `X-API-Key` проверяется (если у системы задан
  непустой `api_key`). Сравнение ключа — за константное время.

### systems

Список систем-потребителей. Каждая система:

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | Идентификатор; приводится к нижнему регистру. |
| `name` | string | Человекочитаемое имя. |
| `enabled` | bool | Выключенная система не обслуживается даже при явном указании. |
| `api_key` | string | Общий секрет; пустая строка = без аутентификации. |
| `demask` | bool | Разрешено ли демаскирование. `false` = соответствие не сохраняется вовсе, обратный шаг вернёт присланный payload без изменений. |
| `types` | object | Правила по типам ПД (ключ — идентификатор типа, например `FIO`). |

Правило типа (`TypeRule`):

| Поле | Тип | Описание |
|---|---|---|
| `enabled` | bool | Включено ли маскирование этого типа для системы. |
| `strategy` | string | Стратегия маскирования (см. ниже). |
| `requires_companion` | array | Маскировать только если в том же payload найден хотя бы один из перечисленных типов. Пустой список = всегда. |
| `min_confidence` | float | Нижний порог уверенности детектора; `0` = значение по умолчанию (`0.7`). |

## Стратегии маскирования

| Стратегия | Описание |
|---|---|
| `stars_keep2` | Держит первые и последние 2 алфавитно-цифровых символа, остальное — `*`. Универсальный дефолт. |
| `stars_all` | Прячет все алфавитно-цифровые символы. Для коротких секретов (CVV, PIN). |
| `initials` | Кириллическое ФИО → «И. И. И.». |
| `initials_latin` | Латинское имя (держатель карты) → «I. I.». |
| `label` | Заменяет значение на категорийную метку в скобках, например `[ТЕЛЕФОН]`. |
| `token` | Детерминированный псевдоним `PD_<ТИП>_<hex>`. |
| `synthetic` | Правдоподобный фейк той же формы (другое ФИО, карта, проходящая Luhn, валидная дата). |
| `keep_domain` | Маскирует только локальную часть e-mail, домен сохраняет. |
| `none` | Оставляет значение без изменений (детекция и счётчик работают, маска нет). |

Стратегии по умолчанию для типов: `initials` для `FIO`, `initials_latin` для
`CARD_HOLDER`, `stars_all` для `CVV` и `PIN`, `stars_keep2` для всего остального.
Одиночные `CVV` и `PIN` маскируются по умолчанию. Правило «только в паре»
включается через `requires_companion: ["CARD_NUMBER"]` для нужного типа.

## Готовые пресеты

В `configs/presets/` лежат готовые конфигурации:

- `stars-keep2.json` — дефолт (keep2 для всего, кроме имён и коротких секретов).
- `stars-all.json` — всё прятать звёздами.
- `labels.json` — всё заменять категорийными метками.
- `tokens.json` — всё заменять псевдонимами `PD_*`.
- `synthetic.json` — всё заменять синтетическими значениями.
- `keep-domain.json` — e-mail маскировать с сохранением домена.
- `span-with-labels.json` — как дефолт, но с `span_include_labels: true`.

## Свои типы ПД и справочники

Список идентифицируемых ПД расширяется через конфигурацию, без правки ядра.

### `custom_types`

Каждый элемент описывает один пользовательский тип:

| Поле | Описание |
|---|---|
| `name` | Идентификатор типа: `^[A-Z][A-Z0-9_]{1,40}$`, не совпадает со встроенным типом. |
| `pattern` | Go-регулярное выражение, ищется в тексте. |
| `anchors` | Слова-якоря (без учёта регистра, по границе слова). Непустой список означает, что совпадение принимается, только если якорь стоит не дальше `window` байт слева. |
| `window` | Окно якоря в байтах; по умолчанию 40, допустимо 0..200. |
| `strategy` | Стратегия маскирования (см. «Стратегии маскирования»). |
| `label` | Метка для стратегии `label`; пустая — `[ПД]`. |
| `min_confidence` | Порог уверенности; по умолчанию 0.7. |

Пример — номер договора рядом со словом «договор»:

```json
{
  "custom_types": [
    {
      "name": "CONTRACT_NUMBER",
      "pattern": "\\d{2}-\\d{6}",
      "anchors": ["договор"],
      "window": 40,
      "strategy": "stars_keep2",
      "label": "[ДОГОВОР]",
      "min_confidence": 0.7
    }
  ]
}
```

Тип включён для системы, если в её правилах его нет (тогда действуют его
`strategy` и `min_confidence`) либо правило есть и `enabled: true`. При
пересечении со встроенным типом побеждает встроенный. В метриках
пользовательские типы считаются под одной меткой `custom`.

### `dictionaries`

Дополнения к встроенным справочникам-вето:

| Поле | Описание |
|---|---|
| `famous_people` | Полные имена публичных персон, упоминание которых не является ПД. |
| `bank_places` | Топонимы отделений банка, которые не маскируются как адрес клиента. |

```json
{
  "dictionaries": {
    "famous_people": ["иван иванов"],
    "bank_places": ["головной офис на набережной"]
  }
}
```

Изменения `custom_types` и `dictionaries` применяются на лету через
`PUT /admin/config` без перезапуска.

## Применение на лету

`GET /admin/config` возвращает текущую конфигурацию (секреты заменены на
`***`). `PUT /admin/config` валидирует, публикует атомарно и пишет на диск
(через временный файл + rename). Невалидная конфигурация отвергается, работающая
остаётся нетронутой. Система с `api_key: "***"` сохраняет прежний ключ, поэтому
цикл GET → правка → PUT не уничтожает секрет.

Админ-роуты защищены токеном из `PDGUARD_ADMIN_TOKEN` (приоритет) или
`server.admin_token`. Пустой токен оставляет их открытыми — это удобно для
локальной демонстрации, но не для реального деплоя; стартовый лог предупреждает
об этом.

## Переменные окружения

| Переменная | Описание |
|---|---|
| `PDGUARD_CONFIG` | Путь к файлу конфигурации. |
| `PDGUARD_ADDR` | Адрес прослушивания (перекрывает `server.addr`). |
| `PDGUARD_LOG_LEVEL` | Уровень логов (перекрывает `log.level`). |
| `PDGUARD_LOG_FORMAT` | Формат логов (перекрывает `log.format`). |
| `PDGUARD_ADMIN_TOKEN` | Токен админ-роутов (перекрывает `server.admin_token`). |
| `PDGUARD_LLM_API_KEY` | Ключ API для LLM-апстрима (только из окружения). |
| `GOMEMLIMIT` | Если задан, перекрывает вывод лимита памяти из cgroup. |

Приоритет: флаг > переменная окружения > файл > встроенный дефолт.
