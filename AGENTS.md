# pdguard — правила работы в этом репозитории

Сервис «Модуль безопасности персональных данных»: HTTP-прокси между системой-потребителем
и LLM. Находит в тексте персональные данные, заменяет их масками, и по тому же `payload_id`
возвращает исходный текст обратно. Контракт — единственный эндпоинт `POST /process`
(см. `process_api.yaml`), обслуживающий и прямой, и обратный шаг.

## Жёсткие правила

1. **Go 1.25, module `pdguard`. ТОЛЬКО стандартная библиотека.** Никаких сторонних
   зависимостей. `go.mod` менять нельзя — в нём должно остаться ровно две строки.
2. **Каждый файл обязан проходить `gofmt`.** Отступы — табы. В конце файла — перевод строки.
3. Doc-комментарии к пакетам и экспортированным идентификаторам — **на английском**,
   в каноническом стиле Go (`// Name does ...`). Пояснения к доменной логике внутри
   функций можно писать по-русски.
4. Не создавай файлов сверх перечисленных в задании. Не трогай `*_test.go` — тесты
   заданы заранее и являются контрактом: подгонять тест под код запрещено, код должен
   удовлетворять тесту.
5. Не трогай `testdata/`, `configs/`, `go.mod`, `Makefile`, `Dockerfile`, `scripts/`.

## Временные файлы — только внутри репозитория

OpenCode запрещает запись за пределы каталога проекта: попытка создать файл в
системном временном каталоге (`AppData\Local\Temp`, `/tmp`, `$TMPDIR`) будет
автоматически отклонена и прервёт всю задачу целиком.

Все временные файлы — тела запросов для `curl`, черновики скриптов, вывод команд —
клади в `./.tmp/` внутри репозитория. Каталог уже создан и исключён из упаковки.
Не используй `mktemp` без явного `-p ./.tmp`.

## Toolchain — Go стоит в Docker, а не в PATH

В этом окружении **нет `go` в PATH**. Любая команда Go запускается через обёртки:

```bash
timeout 600 bash scripts/go.sh build ./...          # компиляция
timeout 600 bash scripts/go.sh vet ./...            # статический анализ
timeout 900 bash scripts/go.sh test ./... -count=1  # тесты
timeout 600 bash scripts/go.sh test ./internal/pd/detect/ -count=1 -run TestFIO   # точечно
timeout 300 bash scripts/gofmt.sh -l .              # список неотформатированных файлов (пусто = ок)
timeout 300 bash scripts/gofmt.sh -w internal/pd/types.go   # отформатировать файл на месте
```

**Всегда оборачивай команды toolchain в `timeout`** — docker иногда занят,
и без `timeout` команда может повиснуть без вывода. Если команда вернула
код 124, это таймаут: просто повтори её.

**Всегда заканчивай работу так:** `bash scripts/gofmt.sh -l .` → пусто,
затем `bash scripts/go.sh build ./...` → без ошибок. Если пакет уже покрыт тестами —
`bash scripts/go.sh test ./<пакет>/ -count=1`.

Первый запуск каждой команды тянет docker-образ и занимает до минуты — это нормально,
дождись результата, не отменяй.

## Архитектура

```
cmd/server                 процесс: флаги, окружение, listener, сигналы, слив
└── internal/httpapi       транспорт: маршруты, admission control, таймауты, /admin
    └── internal/engine    ядро: направление операции, фильтрация по конфигурации
        ├── internal/config   живая конфигурация, атомарная замена
        ├── internal/store    соответствия payload_id → (оригинал, маска)
        └── internal/pd       предметная область
            ├── pd            каталог типов, Span, приоритеты
            ├── pd/text       лоукейс с сохранением смещений, токенизация
            ├── pd/dict       словари (встроены через go:embed)
            ├── pd/detect     контракт детектора, контекст, резолвер, детекторы
            └── pd/mask       контракт стратегии, применение и восстановление
    internal/logging       логгер со скрабингом (используется всеми)
    internal/metrics       счётчики и экспозиция Prometheus (используется всеми)
```

Зависимости направлены строго внутрь: `pd/*` ничего не знает про HTTP и конфигурацию.

## Инварианты, которые нельзя нарушать

- **Байтовые смещения.** `pd.Span` — полуоткрытый диапазон `[Start,End)` в байтах по
  ИСХОДНОМУ тексту. `text.SafeLower` обязан сохранять длину в байтах, иначе смещения
  детекторов разъедутся.
- **Обратимость.** Текст вне найденных спанов не проходит никакого преобразования:
  результат собирается как «копия промежутка → маска → копия промежутка».
  Демаскирование обязано возвращать исходную строку байт в байт.
- **ПД не попадают в логи и метрики.** Ни в каком виде, ни на каком уровне.
- **Идемпотентность по `payload_id`.** Повторный запрос с тем же id безопасен.
